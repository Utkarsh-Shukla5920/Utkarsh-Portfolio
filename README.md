# Utkarsh Portfolio

## About the Project
This is my personal portfolio website, created using HTML and CSS to show my profile, skills, and contact information.

## Features
- Navigation bar 
- About Me section with personal info and education
- Skills section
- Contact information and contact form
- Responsive layout for different screen sizes

## Technologies Used
- HTML5
- CSS3

## How to Run
1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.

## What I Learned
While building this project, I practised structuring web pages with HTML, styling layouts with CSS, and making the website responsive.
